# Changelog

## 1.0.0 — 2026-11-06

First release.

- Four quiz modes: continue the ayah, start of a rub', name the rub', link the quarters.
- Choose what you've memorized by juz, hizb, surah or ayah range.
- Spaced repetition (FSRS) per ayah and per quarter, weakest first; missed items return within the session.
- Progress map of all 240 quarters.
- The full mushaf: surah and juz index, the 604 Madani pages read one by one (buttons, swipe, arrow keys, go to page), with the last page remembered.
- Optional English translation in the reader, ayah by ayah: Saheeh International or Pickthall.
- Arabic and English interface with right-to-left layout; light and dark themes in a soft amethyst palette.
- Works offline and installs as an app.
- Optional accounts with email-code sign-in and conflict-free sync across devices (Supabase).
- Backup download and restore.
- Tanzil Uthmani text (Hafs), with boundaries checked against in-text rub' signs and quran.com.
